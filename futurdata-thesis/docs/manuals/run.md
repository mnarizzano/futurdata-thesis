# Running the application

From `futurdata-thesis/`, activate the environment created during installation:

```sh
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python run_app.py
```

Use **File -> Export Document -> HTML/Web (.html)...** to create an HTML guide
from the active diagram. PowerPoint and Word exports are available in the same menu.
