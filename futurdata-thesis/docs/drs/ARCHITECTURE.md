# ARIADNE architecture (JSON-only MVC)

ARIADNE now uses **JSON-only persistence**. SQLite is not used at runtime.

## MVC boundaries

- **Model** (`src/main/models/`): diagram, shapes and connections. These classes contain domain state only.
- **View** (`src/main/views/`): Tkinter UI. Views render state and collect user input; persistence is accessed through the controller/repository dependency rather than SQL.
- **Controller** (`src/main/controllers/app_controller.py`): coordinates user actions, model mutations, persistence and import/export.
- **Repository** (`src/main/repositories/json_repository.py`): the single persistence boundary. It replaces the former SQLite manager and stores products, components, steps, actions, catalogs and relationships in `~/.disassembly_diagram/ariadne_data.json` using atomic file replacement.
- **Services** (`src/main/services/`): application workflows that are not UI or domain objects. `ProjectArchiveService` creates/imports portable ZIP projects.

## Persistent JSON

The repository document contains named collections for colors, materials and their hierarchy, tools, actions, root/intermediate/leaf components, disassembly steps, step/action links, and step outputs. Numeric IDs are generated by per-collection counters. The existing encoded component-ID convention is retained for compatibility with the diagram model.

## Portable export format

**Export Project** writes a `.zip` file with:

```text
project.zip
├── diagram.json
└── images/
    └── ... referenced component/step/action images ...
```

`diagram.json` contains the diagram geometry, properties, connections and persistence metadata. Image paths remain relative (`images/...`) so archives are portable. Import validates archive paths before extraction and restores images into the application image store.

## Compatibility

Legacy diagram fields and encoded component IDs are retained. Database shim and
migration modules are no longer present; runtime persistence is provided by
`JsonRepository`. HTML export is provided by
`src/main/services/html_exporter/`, through the application document export service.

Document conversion uses the active diagram snapshot, not the persistence JSON.
See [MVC_ARCHITECTURE.md](MVC_ARCHITECTURE.md) for the controller/service flow.
